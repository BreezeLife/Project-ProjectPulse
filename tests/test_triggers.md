# Skill trigger evaluation

Positive: `project pulse`, `where are we?`, `what is done?`, `what remains?`, `what is blocked?`, `what can I test now?`, `ready for review`, `ready for release`, `handoff`, `resume project`, `check project status`.

Negative: `explain this Python function`, `fix the failing unit test`, `add a button`, `how do I use Git rebase?`, `review this algorithm for complexity`.
