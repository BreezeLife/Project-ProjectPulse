# User scenarios

Project Pulse covers: where are we; new coding-agent sessions; switching machines; switching agents; asking what can be tested; checking whether implementation is actually finished; human and agent handoffs; multiple agents and dirty worktrees; Git worktrees; repositories without `TASKS.md`; new non-Git prototypes; review readiness; release readiness; founder or project-manager checks; long-running projects; and hostile or unknown repositories.

In every case, the current root and snapshot are resolved first. The report separates verified work from implemented but unverified work, active and blocked work, unknowns, readiness, evidence, and next actions.
