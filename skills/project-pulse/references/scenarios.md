# Scenario routing

Use the same inspect operation for status, new-session reconstruction, machine or agent handoff, worktrees, unfamiliar repositories, prototypes, and long-running projects. Use the report's readiness section for "what can I test now?", "ready for review?", and "ready for release?". Use `STALE` to signal a changed snapshot. Use `UNKNOWN` where a repository has no task docs, policy, or verification evidence. Do not summarize historical logs unless the user asks.
